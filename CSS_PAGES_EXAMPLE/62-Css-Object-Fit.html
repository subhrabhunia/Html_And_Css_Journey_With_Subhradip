62 - CSS Object-Fit and Object-Position

1. object-fit: fill

Image stretches to fill the complete container.

2. object-fit: contain

Complete image is visible inside the container.

3. object-fit: cover

Image completely covers the container. Some parts may be cropped.

4. object-fit: none

Image keeps its original size.

5. object-fit: scale-down

Uses the smaller size between none and contain.
