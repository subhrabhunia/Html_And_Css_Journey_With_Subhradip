CSS @Import Rule

Importing one CSS file into another CSS file

1. Basic @import

The @import rule is used to import another CSS file.

@import url("reset.css");

2. Import CSS File

External CSS files can be imported into the main CSS file.

This style can come from an imported CSS file.

3. Multiple CSS Files

More than one CSS file can be imported.

reset.css
colors.css
buttons.css
layout.css

4. Import Google Font

Google Fonts can also be imported using the @import rule.

Imported Font Example

@import url("https://fonts.googleapis.com/css2?family=Poppins&display=swap");

5. @import with Media Query

CSS can be imported only when a particular media condition is satisfied.

Screen Media
@import url("screen.css") screen;

6. @import print

A CSS file can be imported specifically for printing.

Print Style Example
@import url("print.css") print;

7. @import with supports()

CSS can be imported when the browser supports a particular CSS feature.

CSS Feature Support
@import url("grid.css") supports(display: grid);

8. @import URL

The url() function can specify the location of the CSS file.

External CSS Resource
@import url("style.css");

9. @import Order

Imported CSS should normally be placed before the other CSS rules.

Import → Variables → Components → Layout

10. Imported CSS Variables

An imported stylesheet can contain CSS custom properties.

CSS Variable Example

11. Imported Utility Classes

Utility classes can be defined in another CSS file and imported.
