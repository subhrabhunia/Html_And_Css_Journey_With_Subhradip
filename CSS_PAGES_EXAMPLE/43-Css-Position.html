CSS Position controls how an element is placed on the webpage.

Position properties are useful for creating layouts.

Relative position moves an element from its normal position.

Absolute position is positioned relative to its nearest positioned parent.

Fixed position stays in the same place on the screen.

Sticky position behaves like relative until a scroll position is reached.
