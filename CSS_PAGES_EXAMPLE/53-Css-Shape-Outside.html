CSS SHAPE-OUTSIDE

Circle Shape

CSS is a powerful language used to style and design web pages. The shape-outside property allows text to flow around the shape of a floated element. Instead of text following only the rectangular boundary, it can follow a circle, ellipse, polygon, or image shape. This is useful for creating attractive magazine-style layouts and modern web designs.

Ellipse Shape

The shape-outside property defines the shape around which inline content should wrap. It works with floated elements and can create interesting text layouts. The ellipse function can be used when the text needs to flow around an oval-shaped element. This technique is useful for articles, blogs, magazines, and creative landing pages.

Polygon Shape

Polygon shapes allow developers to create custom boundaries for text wrapping. Multiple points can be provided to create triangles, diamonds, hexagons, or other shapes. The text automatically flows around the defined shape when the element is floated.

None

When shape-outside is set to none, the content flows around the normal rectangular box of the floated element. No special shape is applied to the element. This is the default behavior of shape-outside.
